# Godot GStreamer

Данный репозиторий содержит плагин, выступающий в роли враппера для взаимодействия с библиотекой GStreamer из Godot.
Также в нём хранится тестовый Godot-проект, демонстрирующий работу плагина. ВАЖНО: Используемый в проекте пайплайн для запуска sink-потока GStreamer написан для компьютера с видеокартой Nvidia. Пайплайн необходимо менять в зависимости от железа.

ПОДДЕРЖИВАЕТСЯ **ТОЛЬКО** ПЛАТФОРМА **LINUX**

## Подготовка к разработке
Необходимо наличие:
* CMake, C++ компилятор
* [GStreamer](https://gstreamer.freedesktop.org/documentation/installing/on-linux.html?gi-language=c)

Внутри репозитория содержится **сабмодуль** [godot-cpp](https://github.com/godotengine/godot-cpp), используемый для сборки плагина. Версия этого сабмодуля должна соответствовать первым двум цифрам версии движка (например, 4.3), для которой разрабатывается плагин. Для этого можно либо вручную скачать код из соответствующей ветки в репозитории сабмодуля, либо, если репозиторий данного проекта был скопирован через git, то можно использовать команды:
```
git submodule update --init --recursive
cd godot-cpp
git checkout <нужная ветка>
```

### Использование VS Code
Для сборки плагина использовался пакет **CMake**, для дебага - пакет **CodeLLDB**. Установив эти пакеты и указав в `.json` файлах в папке `.vs` пути до библиотек, движка и проектов, можно быстро настроить удобный воркфлоу для сборки плагина, его запуска вместе с тестовым Godot-проектом и дебага. 

## Получение кадров из некого источника
Плагин поддерживает создание любого количества потоков, которые будут принимать кадры из каких-либо источников.
### Список методов:
#### *start_sink_stream(godot::String pipeline_desc)*
Принимает пайплайн для создание потока-стока (sink), который будет принимать кадры, полученные по определённому айпи и порту.

Подразумевает получение именно sink-пайплайна. 

#### *get_sink_image(int port)*
Возвращает ссылку на Годотовский объект Image, хранящий в себе последний актуальный кадр, полученный после обращения к sink-потоку, соответствующий указанному порту.

#### *stop_sink_stream(int port)*
Останавливаем sink-поток, соотвествующий указанному порту.
